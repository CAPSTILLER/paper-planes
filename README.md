# Paper Plane Academy

Kid-friendly app: fold 10 paper airplanes step by step (Beginner, Pro, Master) and learn the science of flight. Fold diagrams are generated by a small flat-folding engine (src/fold.js). No ads, no accounts, no tracking. Works offline (PWA).

```
npm install
npm run dev
npm run build
```

Vercel: framework Vite, output dist.
